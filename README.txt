  批量分组发送邮件工具 使用说明
========================================

【功能简介】
本工具用于批量发送邮件，支持：
- 从 Excel 名单导入收件人（单位、职务、姓名、邮箱）
- 按单位、职务筛选收件人
- 逐个勾选收件人，区分收件人/抄送
- 按单位匹配附件（各单位只发本单位附件）
- 富文本正文编辑（加粗/斜体/下划线/字号/对齐）
- 发送预览与实时进度显示

【使用方法】
1. 解压本文件夹到任意位置
2. 编辑 conf.json，填入您的 SMTP 邮箱信息
3. 准备"收件人名单.xlsx"（放在 exe 同级目录）
   - 表格需包含4列：单位、职务、姓名、邮箱
4. 双击"批量分组发送邮件.exe"
5. 浏览器会自动打开操作页面
6. 按页面提示操作即可

【conf.json 配置说明】
  smtp_server : SMTP 服务器地址（如 smtp.chinatelecom.cn）
  smtp_port   : SMTP 端口（SSL 通常为 465）
  username    : 发件邮箱地址
  password    : 邮箱密码或授权码
  use_ssl     : 是否启用 SSL（true/false）
  收件人名单   : 名单文件名（默认"收件人名单.xlsx"）

【收件人名单格式】
  单位    职务          姓名    邮箱
  鼓楼    政企主任      张三    zhangsan@xxx.com
  秦淮    政企分管领导  李四    lisi@xxx.com
  ...

【附件说明】
在页面中选择附件根目录，根目录下应按单位名建立子文件夹，
例如：
  附件根目录\
    鼓楼\
      通知.pdf
      方案.docx
    秦淮\
      通知.pdf

各单位收件人只会收到本单位子目录下的附件。

【注意事项】
- 程序启动后会打开浏览器，请勿关闭浏览器窗口
- 关闭浏览器后，如需继续使用请重新双击 exe
- 程序仅在本机运行，不会上传任何数据到外部服务器
- 发送间隔约1秒，避免被邮件服务器限制

【系统要求】
- Windows 7 SP1 及以上
- 浏览器：Chrome 109+ 或 Firefox 115+ 或 Edge
- 无需安装任何其他软件
