  批量分组发送邮件工具 使用说明
========================================

【功能简介】
本工具用于批量发送邮件，支持：
- 从 Excel 名单导入收件人（分组、部门、姓名、邮箱）
- 按分组、部门筛选收件人
- 逐个勾选收件人，区分收件人/抄送
- 按部门匹配附件（各部门只发本部门附件）
- 富文本正文编辑（加粗/斜体/下划线/字号/对齐/列表/链接/图片）
- 发送预览与实时进度显示
- 一键生成标准模板 Excel
- 页面内直接修改 SMTP 配置并测试连接
- 随机等待发送（每封邮件间隔 2-6 秒，规避邮件服务器风控）
- 系统托盘图标（右键菜单可打开网页/启停服务/退出）

【使用方法】
1. 解压本文件夹到任意位置
2. 编辑 conf.json，填入您的 SMTP 邮箱信息
   （也可启动后在页面"设置"中修改，无需手动编辑文件）
3. 准备"收件人名单.xlsx"（放在 exe 同级目录）
   - 如需模板：在页面"筛选收件人分组、部门"弹出层中点击"生成模板"按钮
   - 或按下方格式自行制作
4. 双击"批量分组发送邮件.exe"
5. 浏览器会自动打开操作页面
6. 按页面提示操作即可

【conf.json 配置说明】
  smtp_server      : SMTP 服务器地址（如 smtp.chinatelecom.cn）
  smtp_port        : SMTP 端口（SSL 通常为 465）
  username         : 发件邮箱地址
  password         : 邮箱密码或授权码
  use_ssl          : 是否启用 SSL（true/false）
  port             : 本地服务端口（默认 8460，一般无需修改）
  random_delay     : 随机等待发送（默认 true，开启后每封邮件间隔 2-6 秒）
  recipient_file   : 名单文件名（默认"收件人名单.xlsx"）
  sheet_recipients : 收件人所在 sheet 名（默认"收件人名单"）
  sheet_depts      : 部门排序表 sheet 名（默认"部门"）
  sheet_groups     : 分组排序表 sheet 名（默认"分组"）

【收件人名单.xlsx 格式】

  Sheet1 "收件人名单"：
    分组          部门      姓名    邮箱
    岗位类型A     部门1     张三    zhangsan@xxx.com
    岗位类型A     部门2     李四    lisi@xxx.com
    ...

  Sheet2 "部门"：
    展示排序    部门
    1          部门1
    2          部门2
    ...

  Sheet3 "分组"：
    展示排序    分组
    1          岗位类型A
    2          岗位类型B
    ...

  提示：页面筛选弹出层中有"生成模板"按钮，可一键下载标准模板。

【附件说明】
在页面中选择附件根目录，根目录下应按部门名建立子文件夹，
例如：
  附件根目录\
    部门1\
      通知.pdf
      方案.docx
    部门2\
      通知.pdf

各部门收件人只会收到本部门子目录下的附件。

【系统托盘】
- 程序启动后，右下角托盘区会出现图标
- 服务运行时图标显示为"已启用"，停止后变为"已停止"
- 右键托盘图标可：打开网页、启动服务、停止服务、退出
- 左键点击托盘图标同样弹出菜单
- 页面中点击"关闭服务"按钮也可关闭服务，托盘图标会同步变化
- 关闭浏览器标签页时服务会自动关闭，刷新页面不会关闭服务

【注意事项】
- 程序仅在本地 127.0.0.1 运行，不会上传任何数据到外部服务器
- 用完建议点击"关闭服务"或从托盘退出，释放端口避免被内网扫描
- 随机等待发送默认开启（每封间隔 2-6 秒），可在设置中关闭
- 如需更改端口，编辑 conf.json 中的 port 字段

【系统要求】
- Windows 7 SP1 及以上
- 浏览器：Chrome 109+ 或 Firefox 115+ 或 Edge
- 无需安装任何其他软件
