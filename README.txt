使用说明
========================================

【功能简介】
按部门批量发送邮件，每个部门只收到本部门的附件。
支持从 Excel 导入收件人名单、富文本正文编辑、发送预览。
随机等待发送（每封间隔 2-6 秒），规避邮件服务器风控。

【使用方法】
1. 解压到任意位置
2. 双击"多部门点对点一键发送邮件.exe"，浏览器自动打开操作页面
3. 在"设置"中填入 SMTP 邮箱信息，或手动编辑 conf.json
4. 准备"收件人名单.xlsx"（放在 exe 同级目录，也可在页面中生成模板）
5. 按页面提示操作即可

【收件人名单.xlsx 格式】
  Sheet1 "收件人名单"：分组 / 部门 / 姓名 / 邮箱
  Sheet2 "部门"：展示排序 / 部门
  Sheet3 "分组"：展示排序 / 分组
  提示：页面中有"生成模板"按钮，可一键下载标准模板。

【附件说明】
选择附件根目录后，根目录下按部门名建子文件夹，
各部门收件人只会收到本部门子目录下的附件。

【注意事项】
- 程序仅在本地 127.0.0.1 运行，不会上传任何数据
- Windows 7 SP1 及以上，无需安装任何其他软件
- 用完建议点击"关闭服务"或从托盘退出
